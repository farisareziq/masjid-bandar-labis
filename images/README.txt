FOLDER GAMBAR / IMAGES
======================

1) qr-sumbangan.jpg  (PENTING - QR Sumbangan)
   Letakkan imej DuitNow QR RASMI daripada aplikasi Bank Rakyat
   di sini dengan nama:  qr-sumbangan.jpg
   Website akan memaparkannya secara automatik di seksyen Sumbangan
   (dan boleh dibesarkan dengan klik untuk scan).
   Tanpa fail ini, laman akan memaparkan placeholder sahaja.

2) logo.png  (Logo masjid)
   Letakkan logo masjid di sini dengan nama:  logo.png
   Logo akan dipaparkan di navbar (atas) dan footer secara automatik.
   Format yang disarankan: PNG dengan latar telus (transparent),
   saiz sekitar 500x500px. Fail .jpg/.svg juga boleh, guna nama yang sama.
   Tanpa fail ini, ikon emoji 🕌 dipaparkan sebagai ganti.

3) carta-pentadbiran.jpg  (Carta organisasi)
   Dipaparkan dalam halaman Tentang -> Carta Organisasi.

4) Galeri/  (Foto galeri - dipaparkan automatik di halaman Galeri
   dan slider di halaman Utama)

5) Musafir Inn/  (Foto Musafir Inn - gambar pertama dipaparkan
   dalam halaman Perkhidmatan)

Nota:
- Semua gambar akan dikompres kepada saiz web (maks 1600px, kualiti 80)
  menggunakan scripts\optimize-images.ps1.
- JANGAN letak maklumat peribadi, kata laluan atau fail sensitif di sini.
- Semua fail dalam folder ini akan dipaparkan secara AWAM di GitHub Pages.
